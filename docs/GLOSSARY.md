# The reference codes in the comments

Source comments cite a development record kept outside this repository, in short codes. The key:
**C`n`** is a chunk of work (C9 the living world, C11 the deep world, C13 the presentation pass);
**G`n`** with an optional letter is a gate run that closed a chunk (G6, G9a, G11a, G11b) — a few
of those gates are checked in, as `g6.test.ts`, `g9.test.ts`, `g11.*.test.ts`; **R`n`** is a
numbered controller ruling, and *"ruling `n`"* spelled out means the same thing; **T`n`** is a
task inside one plan, and **OD`n`** an open decision in it; **P`n`** and **U`n`** are numbered
items from the presentation plan and from the owner's review of it; **addendum §`n`** is a
section of a spec addendum under [superpowers/specs](superpowers/specs). The plans and specs
those codes were written against are under [superpowers/](superpowers); the rulings themselves
are not in the tree. A comment is written to stand without its code — if one does not, the code
is not the fix.
