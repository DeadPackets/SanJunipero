# C3 — One Living Agent Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `@sj/agents` — the mind half of the contract: OpenRouter client wrapper, turn schema with repair + in-world fallback, per-agent memory store (verbatim + FTS5 + sqlite-vec hybrid retrieval + miss-log), personality versioning with drift-limiter, prompt assembler with the strict stability gradient, sleep reflection, dreams, wake scheduler, and one agent living 2 full sim days against real DeepSeek (GATE G3).

**Architecture:** The mind is an async loop that never blocks the tick loop: an `EngineBridge` queues intents (drained in arrival order at the next tick, per spec §2) and composes perception from live state; the `AgentRuntime` wakes on policy triggers, assembles a cache-stable prompt, gets one schema-validated turn from DeepSeek, and writes every perception/thought/action verbatim into an agent-fenced memory store. Sleep runs the reflection pipeline (facts → summaries → ledgers → autobiography → ≤1 personality edit) and IS the context compaction. All LLM-touching modules take injected model/deps so every task except the probe and the gate tests against mocks.

**Tech Stack:** Node 24, TypeScript ESM, Vitest, better-sqlite3 v13 (WAL), Zod 4, Vercel AI SDK 7 (`ai@^7`) + `@openrouter/ai-sdk-provider@^3`, `sqlite-vec@0.1.9` (exact pin), `@huggingface/transformers@^4` with `Xenova/bge-small-en-v1.5`.

**Spec:** `docs/superpowers/specs/2026-08-15-san-junipero-design.md` §5 (agent minds), §6 (memory), §2 (non-blocking minds), §15 (LLM layer + data/runtime stack). Roadmap: `2026-08-15-00-master-roadmap.md` (C3 block, Global constraints, Cross-chunk rules — the $5 probe rule). C2 plan `2026-08-15-02-physics-verbs.md` Tasks 5 & 13 define the frozen contracts below.

## Global Constraints

- Mind model: `deepseek/deepseek-v4-flash-0731` — pinned dated snapshot, never `-latest`. Pricing constants (verified in spec §1): $0.14/M input, $0.28/M output, $0.028/M cache read.
- All LLM calls go through Vercel AI SDK 7 (`ai@^7`) + `@openrouter/ai-sdk-provider@^3` as a thin call layer only (retries, Zod structured output via `Output.object`, usage accounting). No framework agent loop.
- Failover: OpenRouter `models: []` fallback array passed via `extraBody`. Caching: pin `provider.order` (values discovered by Task 1's probe, committed as constants) so warm prefixes never cold-start on a routing hop. Log `usage.inputTokenDetails.cacheReadTokens` on EVERY call — a silent cache miss is a 5× input-cost bug.
- Zod 4 for every schema (`z.toJSONSchema()` only); all new object schemas `.strict()`.
- SQLite via `better-sqlite3` v13, WAL, ONE db file (`data/town.db` in prod, `:memory:`/temp in tests). Per-agent memory isolation is enforced at the query layer: every `MemoryStore` statement is `agent_id`-fenced (spec §6) — cross-agent retrieval structurally impossible.
- Embeddings: `sqlite-vec` 0.1.9 (exact pin, pre-v1) + `@huggingface/transformers` v4, model `Xenova/bge-small-en-v1.5` (384-dim, CPU, local, free), `env.cacheDir` persisted at `data/models`. **fastembed-js is archived — do not use.**
- Human framing law: no world text, block template, or perception prose ever references AI, prompts, tokens, models, or tools. Enforced by a regex test in Task 8 and re-asserted at the gate.
- Live-API discipline: Task 1 is a $5-capped probe; nothing that talks to OpenRouter is built before it passes. Live tests use the `*.livetest.ts` suffix (root vitest include `packages/*/src/**/*.test.ts` never matches them; they run only via `pnpm test:live` with `OPENROUTER_API_KEY` set). CI stays offline and green.
- `OPENROUTER_API_KEY` comes from env only. (Roadmap OPS note: a key was committed in early local history — rotate before any remote push.)
- Determinism where the world can see it: dreams and any mind-side randomness use seeded `RngStream`s (seed = `agentId:day`), never `Math.random`. Engine RNG law untouched — minds emit intents, never events.
- Golden replay (G1) and the G2 suite stay green through this whole chunk; `pnpm test && pnpm typecheck` before every commit.
- Worktree gotcha: EnterWorktree branches from stale origin/main — first action after creating the worktree is `git merge main --ff`.
- TDD per task: failing test first (RED evidence), implement, GREEN, full suite + typecheck, commit per task. The only TDD-exempt task is the probe (it is an experiment; its evidence is captured output).

```ts
import { generateText, Output } from 'ai'
import { createOpenRouter } from '@openrouter/ai-sdk-provider'
import { z } from 'zod'

const MODEL = 'deepseek/deepseek-v4-flash-0731'
const CAP_USD = 5.0
let spentUsd = 0
function book(usage: any, label: string) {
  const cin = usage?.inputTokenDetails?.cacheReadTokens ?? 0
  const cost = ((usage.inputTokens - cin) * 0.14 + cin * 0.028 + usage.outputTokens * 0.28) / 1e6
  spentUsd += cost
  console.log(`[${label}] in=${usage.inputTokens} out=${usage.outputTokens} cacheRead=${cin} cost=$${cost.toFixed(6)} total=$${spentUsd.toFixed(4)}`)
  if (spentUsd > CAP_USD) { console.error('BUDGET CAP EXCEEDED'); process.exit(1) }
  return cin
}
const openrouter = createOpenRouter({ apiKey: process.env.OPENROUTER_API_KEY! })
```
