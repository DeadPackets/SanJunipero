# C4 — Arbiter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `@sj/arbiter` — the Tier-2 "LLM God layer": a freeform-intent adjudication prompt (canon + skills/inventory + precedent), a `map`/`attempt`/`impossible` verdict schema whose `attempt` carries an outcome table the engine can roll, codification of successful novel rulings into the `rulebook` table with hot-registration into C2's `VERBS` registry, a `rulings` precedent store with similarity retrieval, the adjacency doctrine against the knowledge codex, an admin review/revert queue, and a chaos-agent fuzz suite — gated by G4 (0 physics-breaking rulings; a novel "boil river water for salt" intent resolves Tier-1 on its second attempt with zero Arbiter LLM calls).

**Architecture:** The Arbiter is an async, non-blocking adjudication service consumed by the engine/runtime, never awaited by the tick loop. `makeArbiter(deps)` returns `{ adjudicate(intent, agentCtx) }` where `adjudicate` is a three-stage funnel: (1) deterministic `rulebook` lookup — an exact normalized-name match returns `{kind:'map'}` with **zero LLM calls**; (2) deterministic `rulings` similarity short-circuit — a cosine ≥ `SIMILARITY_SHORT_CIRCUIT` returns the stored verdict verbatim, also zero LLM; (3) only genuinely novel intents reach the LLM, which returns one `VerdictSchema`-validated structured verdict, then the ruling is recorded in `rulings`. Codified recipes are compiled to a real `VerbDef` (`validate`/`duration`/`onStart`/`onComplete`/`rngStream`) and `registerVerb`-ed into `@sj/engine`'s `VERBS`, so a second attempt is plain Tier-1 physics. The LLM can only emit a whitelisted `OutcomeEffect` vocabulary (spawn_item / gain_skill / hp_delta / none) — never raw event types — which is the anti-exploit hard floor.

**Tech Stack:** Node 24, TypeScript ESM, Vitest, better-sqlite3 v13 (WAL), Zod 4, `sqlite-vec@0.1.9` (exact pin). Reuses `@sj/agents`' `LlmClient` (Vercel AI SDK 7 + `@openrouter/ai-sdk-provider@^3`, model `deepseek/deepseek-v4-flash-0731`) and `Embedder` (`Xenova/bge-small-en-v1.5`, 384-dim, local). No new dependencies beyond the monorepo's existing set.

**Spec:** `docs/superpowers/specs/2026-08-15-san-junipero-design.md` §4 (the Arbiter), §2 (event sourcing / non-blocking minds), §3 (deterministic engine, discovery tree), §13 (principal tables), §15 (LLM layer). Roadmap: `2026-08-15-00-master-roadmap.md` (C4 block, Global constraints, Cross-chunk rules — the $5 probe rule, golden replay stays green, LlmClient-only door). C3 plan `2026-08-15-03-agent-mind.md` "Interfaces produced" block (the `LlmClient`/`Embedder`/`MemoryStore`-pattern reuse points).

## Global Constraints

- **Determinism law:** randomness is drawn ONLY at event-creation time by named RNG streams and recorded in event payloads; `fold(events)` is pure and RNG-free. The Arbiter never rolls dice — it authors outcome tables and a `rngStream` name; the engine's `onComplete` draws from that stream. The Arbiter itself emits no events and mutates no world state.
- **LlmClient is the ONLY door to OpenRouter.** The Arbiter imports `LlmClient` from `@sj/agents` (caller `'arbiter'`) and never calls `createOpenRouter`/`generateText` directly. All LLM calls in every test are mocks (scripted `LanguageModel` or scripted `LlmClient`); nothing but the probe and nothing in CI talks to OpenRouter.
- **Zod 4 for every schema** (`z.toJSONSchema()` only); all new object schemas `.strict()`. `VerdictSchema` and `RecipeSchema` are the binding contracts.
- **SQLite via `better-sqlite3` v13, WAL, ONE db file** (`data/town.db` in prod, `:memory:` in tests). Arbiter tables (`codex`, `rulebook`, `rulings`, `ruling_reviews`) are town-global — NOT agent-fenced — because precedent is shared physics, not per-agent memory.
- **Human framing law:** every string an agent can perceive (`Verdict.reason`, `Recipe.name`, `OutcomeRow.label`, `RecipeRequirement` in-world reason strings) must never reference AI/tools/prompts/models. The Arbiter's own system prompt is operator-facing and may describe the task; its *outputs* are asserted framing-free. Enforced by a regex test in Task 4 and re-asserted at the gate.
- **$5 probe rule:** Task 1 is the roadmap-mandated $5-capped live-API experiment; nothing that builds on live calls is written before it passes. Live probes use the root `vitest.live.config.ts` `*.livetest.ts` convention; CI stays offline.
- **Golden replay (G1) and the G2 suite stay green** through the whole chunk; `pnpm test && pnpm typecheck` before every commit. The only engine files C4 touches are `packages/engine/src/verbs.ts` (Task 7, additive `registerVerb`/`unregisterVerb` + a type widening) — no fold/event/systems changes, so the golden hash does NOT change and requires no regen.
- **Adjacency doctrine (spec §4):** a codified recipe may only depend on tech the town has *earned* — every `recipe.canon` id is either already in the codex or exactly one rung beyond a known id (deterministic `CodexStore.withinAdjacency`, Task 3). Nothing is hardcoded-impossible; everything is earned-possible.
- **TDD per task:** failing test first (RED evidence), implement, GREEN, full suite + `pnpm typecheck`, commit per task. The only TDD-exempt task is the probe (Task 1; its evidence is captured output).
- Worktree gotcha: EnterWorktree branches from stale origin/main — first action after creating the worktree is `git merge main --ff`.

```ts
import { z } from 'zod'

export const OutcomeEffectSchema = z.discriminatedUnion('op', [
  z.object({ op: z.literal('spawn_item'), kind: z.string().min(1), qty: z.number().int().positive(), to: z.literal('agent') }).strict(),
  z.object({ op: z.literal('gain_skill'), track: z.string().min(1), xp: z.number().int().positive() }).strict(),
  z.object({ op: z.literal('hp_delta'), delta: z.number().int() }).strict(),        // negative = damage, positive = heal
  z.object({ op: z.literal('none') }).strict(),
]).strict()
export type OutcomeEffect = z.infer<typeof OutcomeEffectSchema>

export const OutcomeRowSchema = z.object({
  weight: z.number().positive(),          // relative weight; engine rolls cumulative sum over rng.next()*total
  success: z.boolean(),                   // true = this row is the success outcome; its weight is skill-scaled at roll time
  label: z.string().min(1),               // in-world result narration (what the agent/others perceive)
  effects: z.array(OutcomeEffectSchema),  // whitelisted engine effects ONLY — the LLM cannot emit raw events
}).strict()
export type OutcomeRow = z.infer<typeof OutcomeRowSchema>
export const OutcomeTableSchema = z.array(OutcomeRowSchema).min(1)
export type OutcomeTable = z.infer<typeof OutcomeTableSchema>

export const RecipeRequirementSchema = z.discriminatedUnion('type', [
  z.object({ type: z.literal('held_item'), kind: z.string().min(1), qty: z.number().int().positive() }).strict(),
  z.object({ type: z.literal('adjacent_tile'), tile: z.enum(['grass','dirt','water','forest','rock','sand','farmland']) }).strict(),
  z.object({ type: z.literal('adjacent_structure'), kind: z.string().min(1) }).strict(),
  z.object({ type: z.literal('adjacent_fire') }).strict(),
]).strict()
export type RecipeRequirement = z.infer<typeof RecipeRequirementSchema>

export const RecipeSchema = z.object({
  id: z.string().regex(/^recipe:[a-z0-9_]+$/),          // deterministic slug (Task 6 slugify)
  name: z.string().min(1),                              // in-world name
  skillCheck: z.object({ track: z.string().min(1), difficulty: z.number().int().min(1).max(10) }).strict().optional(),
  durationTicks: z.number().int().positive(),
  costs: z.array(z.object({ kind: z.string().min(1), qty: z.number().int().positive() }).strict()),
  requires: z.array(RecipeRequirementSchema),
  outcomeTable: OutcomeTableSchema,
  rngStream: z.string().min(1),
  interruptible: z.boolean(),
  canon: z.array(z.string()).min(1),                    // codex tech ids this recipe depends on (adjacency doctrine)
}).strict()
export type Recipe = z.infer<typeof RecipeSchema>

export const ImpossibleClassSchema = z.enum(['physically_impossible', 'beyond_adjacency', 'insufficient_skill', 'insufficient_materials'])

export const VerdictSchema = z.discriminatedUnion('kind', [
  z.object({ kind: z.literal('map'), verb: z.string().min(1), params: z.record(z.string(), z.unknown()) }).strict(),
  z.object({ kind: z.literal('attempt'), recipe: RecipeSchema, summary: z.string().min(1) }).strict(),
  z.object({ kind: z.literal('impossible'), reason: z.string().min(1), class: ImpossibleClassSchema }).strict(),
]).strict()
export type Verdict = z.infer<typeof VerdictSchema>

export function skillFactor(level: number, difficulty: number): number {
  return Math.min(0.95, Math.max(0.05, 0.5 + 0.05 * (level - difficulty)))
}
export function rollOutcomeTable(table: OutcomeRow[], rng: { next(): number }, factor = 1): OutcomeRow {
  const weights = table.map((r) => (r.success ? r.weight * factor : r.weight))
  const total = weights.reduce((a, b) => a + b, 0)
  let roll = rng.next() * total
  for (let i = 0; i < table.length; i++) { roll -= weights[i]; if (roll <= 0) return table[i] }
  return table[table.length - 1]
}
```

## Deviations / resolved ambiguities (flag at review)

1. **`@sj/agents` does not yet re-export `Embedder`/`cosine`/`FakeEmbedder`** though C3's "Interfaces produced" block declares them binding for C4. Task 5 adds the two export lines to `packages/agents/src/index.ts` as part of consuming that declared interface. If C3's final review already added them, that step is a no-op (idempotent).
2. **`VerbDef.kind` widens `VerbKind` → `string`.** The closed `VerbKind` union cannot name arbitrary codified recipes; the engine already keys `VERBS` and looks up by `string`, so the widening is the minimal safe change and does not touch the golden hash.
3. **Outcome effects are a whitelisted `OutcomeEffect` vocabulary, not raw `PendingEvent`s.** Spec says "outcome table the engine can roll"; letting the LLM emit arbitrary event types would be an injection surface. The closed union (`spawn_item`/`gain_skill`/`hp_delta`/`none`) is the anti-exploit floor and is schema-enforced.
4. **Rephrasing consistency is a deterministic similarity short-circuit (`SIMILARITY_SHORT_CIRCUIT = 0.92`), not an LLM judgment.** Exact byte-similar intents hit the rulebook; rephrasings within threshold return the stored verdict verbatim — both with zero LLM calls, which is what makes "reality cannot be rerolled" deterministic rather than prompt-negotiated.
5. **The gate is a self-contained deterministic Vitest suite, not a live run** (mirrors C2's G2, unlike C3's live G3). G4 asserts call-count against a scripted `LlmClient`; live-cost behavior is already proven by Task 1's probe and C3's G3.
