**Goal:** `@sj/narrator` — the omniscient historian: scene segmentation; a hierarchical chronicle (events → scenes → chapters → eras) whose chapters/eras cite event IDs with render-layer verification; deterministic heat scoring (conflict/novelty/firsts/stakes/dramatic irony) feeding director cuts, the digest, and timeline markers; a permanent firsts/milestone ledger; institution detection producing codex entries with founding-scene links; publications (newspaper, weekly biographies from public record only, timelapse captions); and an OG share-card renderer — all behind a one-way glass with no write grant on world tables, gated by G7 (replaying a recorded eventful day yields chapters whose every citation resolves; a 3-day-absence digest renders; the director follows a scripted argument over a scripted idle).

**Architecture:** The narrator is a read-only observer of the immutable event stream. It opens `data/town.db` with a `readonly` connection (the only genuine "no write grant" primitive better-sqlite3 v13 exposes — there is no per-table authorizer in its JS API) and writes its seven observatory tables to a separate `data/narrator.db`. Segmentation, heat, firsts, and institution detection are deterministic pure functions of the event stream; the LLM (`LlmClient`, caller `'narrator'`) authors only prose — chapter/era summaries, newspaper copy, biographies — and every citation it emits is verified against the scene's real event IDs at render time (the hallucination guard). The narrator emits no events and mutates no world state.

**Tech Stack:** Node 24, TypeScript ESM, Vitest, better-sqlite3 v13 (WAL). Reuses `@sj/agents`' `LlmClient` (Vercel AI SDK 7 + `@openrouter/ai-sdk-provider@^3`, model `deepseek/deepseek-v4-flash-0731`), `MIND_MODEL`, `PROVIDER_ORDER`, `FALLBACK_MODELS`, `PRICE_PER_M`, and `migrateLlmTables`. No new dependencies beyond the monorepo's existing set; the share card is a dependency-free hand-rolled SVG string (C8 rasterizes it).

**Spec:** `docs/superpowers/specs/2026-08-15-san-junipero-design.md` §9 (narrator), §2 (architecture / event sourcing), §13 (principal tables), §15 (LLM layer). ## Global Constraints

- **Determinism law:** randomness is drawn ONLY at event-creation time by named RNG streams; `fold(events)` is pure and RNG-free. The narrator draws no randomness anywhere — segmentation, heat, firsts, and institutions are pure functions of the event stream; every LLM output is schema-validated and (for chapters/eras) citation-verified. Re-running the narrator over the same events is idempotent.
- **LlmClient is the ONLY door to OpenRouter.** The narrator imports `LlmClient` from `@sj/agents` (caller `'narrator'`) and never calls `createOpenRouter`/`generateText` directly. All LLM calls in every test are mocks (scripted `LanguageModel` or scripted `LlmClient`); nothing but the probe and nothing in CI talks to OpenRouter.
- **One-way glass (spec §9, by construction):** the narrator reads world + agent tables through a `readonly` connection and writes only its own tables in `data/narrator.db`. No narrator code path can write `data/town.db`. Enforced by a permissions test in Task 3.
- **Zod 4 for every schema** (`z.toJSONSchema()` only); all new object schemas `.strict()`. `ChapterSummarySchema` and `EraSummarySchema` are the binding contracts for citation-carrying prose.
- **Human framing law:** every narrator-authored string that reaches a viewer (chapter/era text, newspaper, biography, timelapse caption, share-card copy) must never reference AI/tools/prompts/models. The narrator's own system prompt is operator-facing and may describe the task; its *outputs* are asserted framing-free via `FORBIDDEN_FRAMING` (Task 8) and re-asserted at the gate.
- **$5 probe rule:** Task 1 is the roadmap-mandated $5-capped live-API experiment; nothing that builds on live calls is written before it passes. Live probes use the root `vitest.live.config.ts` `*.livetest.ts` convention; CI stays offline.
- **Golden replay (G1) and G2 stay green** through the whole chunk; `pnpm test && pnpm typecheck` before every commit. The narrator touches ZERO engine/shared/agents source files — it consumes `@sj/shared` and `@sj/engine` types only — so the golden hash cannot change.
- **SQLite one-DB rule, amended for the narrator only:** world data stays in the single `data/town.db`; the narrator's observatory tables live in `data/narrator.db` because a readonly connection cannot write its own tables and better-sqlite3 v13 has no per-table write grant. Both files are WAL. Flagged as Deviation #1.
- **TDD per task:** failing test first (RED evidence), implement, GREEN, full suite + `pnpm typecheck`, commit per task. The only TDD-exempt task is the probe (Task 1; its evidence is captured output).

```ts
import { openDb } from '@sj/engine'
import { LlmClient, migrateLlmTables } from '@sj/agents'
import { z } from 'zod'

const CANON = 'You are the omniscient historian of San Junipero, a stone-age settlement on a forking river. ' +
  'You write the town chronicle from the immutable event ledger. ' +
  'Every chapter cites events by their ledger number; never invent a number. ' +
  'You speak of the townsfolk as a chronicler would — no mention of models, tools, or prompts. '.repeat(12)

const db = openDb(':memory:')
migrateLlmTables(db)
const llm = new LlmClient({ db, caller: 'narrator', budgetUsd: 5.0 })

const ChapterSummaryProbe = z.object({
  title: z.string().min(1),
  text: z.string().min(1),
  citations: z.array(z.number().int().nonnegative()).max(40),
}).strict()

let spent = 0
function book(usage: any, label: string) {
  spent += usage.costUsd
  console.log(`[${label}] in=${usage.inputTokens} out=${usage.outputTokens} cacheRead=${usage.cacheReadTokens} cost=$${usage.costUsd.toFixed(6)} total=$${spent.toFixed(4)}`)
  if (spent > 5.0) { console.error('BUDGET CAP EXCEEDED'); process.exit(1) }
}
```
Checks (sequential; any throw → exit 1):
1. **Structured citations:** `llm.object({ system: CANON, messages: [{ role: 'user', content: 'Day 1 held three events: [1] Tamar spoke, [2] Omar built a wall, [3] rain fell. Write the day chapter citing only these numbers.' }], schema: ChapterSummaryProbe })` → assert `value.citations` is an array of numbers, all `∈ {1,2,3}`, and `value.title`/`value.text` non-empty. `book(usage, 'structured')`.
2. **Prefix cache:** two calls identical in `system` (the CANON string) differing only in the final user message → assert call 2's `cacheReadTokens > 0` (retry once after a 5s sleep if 0). `book(usage, 'cache')`.
3. **Caller accounting:** assert `llm.totalCostUsd() > 0` and that `db.prepare("SELECT COUNT(*) AS n FROM llm_calls WHERE caller = 'narrator'").get().n >= 2`.

## Deviations / resolved ambiguities (flag at review)

1. **Narrator tables live in `data/narrator.db`, not `data/town.db`.** The roadmap Global constraint says "one DB file `data/town.db`", but a `readonly` connection (the only write-grant primitive better-sqlite3 v13 exposes — it has no per-table authorizer in its JS API) cannot write its own tables. Physical separation is the only genuine "no write grant on world tables"; world data remains single-file in `town.db`, and the narrator's read of `town.db` is `readonly`. C6 reads `narrator.db` for the observatory tables.
2. **No narrator-local pins.** The narrator consumes `MIND_MODEL`/`PROVIDER_ORDER`/`FALLBACK_MODELS`/`PRICE_PER_M` from `@sj/agents` rather than re-observing them (C3's probe already pinned them; the narrator shares the mind model per spec §1).
3. **`first_lie` is not deterministically detectable v1.** "First lie" is semantic (requires judging intent vs. utterance); the deterministic ledger covers the other three spec examples (`first_trade`, `first_law`, `first_death` = "first grave") plus seven more event-derivable firsts. Flagged for C8 tuning; the ledger's `FIRST_DEFS` table is the extension point.
4. **`first_law` is driven by the `rulebook` table, not an event.** C4's arbiter "emits no events" (its codification is a table write), so the milestone reads `rulebookCount` passed into `detectFirsts` rather than matching an event type.
5. **"Agreed rules" are approximated by verb-frequency norms** (a verb performed by ≥2 agents across the week), and "de facto roles" by per-agent verb counts over a threshold. True semantic rule/role extraction needs LLM judgment and is deferred; the deterministic detector is schema-complete and testable now.
