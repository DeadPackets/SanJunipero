## 3. The laws

These are standing. Every one of them was paid for.

### Money and secrets

- **Never read, print, cat, echo or log `.env` or `OPENROUTER_API_KEY`.** A live script runs as
  `node --env-file=<repo>/.env --import tsx <script>` and its output goes through `grep -v sk-`.
- Every call is booked to `_ops.db` at the rate the account is charged. The ledger resumes with
  the town, so a restart never resets a budget.
- Guards on a live town: daily budget `SJ_SPEND_DAILY_USD`, lifetime cap `SJ_SPEND_CAP_USD`,
  rate tripwire (22 calls per mind per sim-hour over 15 min), projection alert ($2.50 per
  sim-day), provider mix. The first three stop the minds and leave the town serving. The last
  two only speak.
- Spend is unlocked by the owner (no per-task caps) which makes unrequested spend worse, not
  better. Never substitute a roster the owner named. Probe a model before trusting a catalogue.

### Production

- The box is production. **Never start, stop, rebuild or `compose down` the production town
  without the owner saying go**, in a user turn, for that action.
- nginx exposes only 8090. `docker compose --profile edge` must never run here (80 and 443 are
  taken by four other sites).
- Rehearsals and shows run on 8099 with admin on 8799.

### Git

- Never `git pull`. Never bare `git stash` (if you must: `git stash push -u -m <tag>`, apply by
  SHA, drop by tag). Prefer a WIP commit.
- Kill processes by PID, never `pkill -f` or `pgrep -f`. Other people's processes match those
  patterns on this box.
- Lanes (subagents) must never stage files. A `git commit` from any path commits the whole
  shared index. Two commits of this drive swept another lane's staged deletions and do not
  typecheck on their own (`be5e8a02`, `5793fdd4`). The tip does.
- Commit attribution the owner asked for is at the foot of every commit of this drive:
  `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` and a `Claude-Session:` line.

### Tests and gates

- **Never run the whole suite. Never run knip.** The full run trips a vitest reporter timeout
  under load and reports a phantom failure, and knip counts a test as a use in this repo
  (`knip.json` lists `**/*.test.ts` as an entry), so it can never find a symbol reached only by
  its own test. Grep for callers by hand.
- One vitest at a time, one gate step per foreground call. A sequential script running the
  whole gate was killed for memory.
- A full gate must name `packages/live` and `packages/town`. Both catch seams that unit tests
  cannot, and both have shipped red tips. `g6.test.ts` (two viewers fold the same events to the
  same bytes over three sim-days) and `liveSeam.test.ts` (the scripted path never loads the mind
  stack) are the proof for any engine or town change.
- Never run any test suite while a rehearsal is running.
- A `★` in a test name or comment is a load-bearing line. Read it before you change what it
  pins. It wins against an audit finding every time.

### Writing

- Plain modern English everywhere a person reads, including a mind's prompt and the town's own
  paper. No captions, no semicolons, no em dashes, no lists of three for rhythm.
- Comments default to none, cap two lines, and only for a constraint the code cannot show.
- Formatting is Biome (`npx biome format --write <files>`), never Prettier.

### Design laws

1. **Physics, never outcomes.** The engine says what wood, rain, hunger and walls do. It never
   says what anybody should do about them. A want is made in the world, not in a prompt.
2. **Story first, never state.** The screen answers who wants something, what is in the way and
   how long it has been going on. It may never state something the world does not hold.
3. **Emergence, never levers.** Nothing steers who likes whom. The world holds facts and refuses
   only what a body cannot do. If a run misbehaves socially, build the lens, not the rule.
4. **The one-way glass.** No operator word reaches a mind (`glassScan`). No story rule reaches a
   mind either.
5. **Additive protocol only.** `PROTOCOL_VERSION` is 8. An unknown frame is dropped in a
   try/catch on the client, so new frames are safe and changed frames are not.
6. The viewer's own rules: no bare unbounded integer on screen, de-emphasis is a colour never an
   opacity, font sizes only `--f-1` to `--f-7` (12/13/14/16/18/22/28), motion only `--t-slow`
   (300 ms) `--t-med` `--t-move` `--stagger`, `contrast.test.ts` holds closed rosters of roles
   and quiet sites, `chromeCss.test.ts` derives the marks the frame places and bans `position`
   on any of them.

```

### Tests, the way that works on this box

One vitest at a time, each in its own foreground call, all at
`--poolOptions.forks.maxForks=1 --silent=true`:

```
npx vitest run packages/web/src/render
npx vitest run packages/web/src/paper packages/web/src/ui packages/web/src/stage
npx vitest run packages/web/src/browserGraph.test.ts packages/web/src/state packages/web/src/net
npx vitest run packages/gateway packages/shared
npx vitest run packages/town          # g6 and liveSeam live here
npx vitest run packages/live
npx vitest run packages/agents
npx vitest run packages/arbiter packages/engine
npx vitest run packages/forge
npx vitest run packages/narrator packages/llm
```

Last measured counts at `42262fd6` (before the CSS-only tip): web 1411 + 1575 + 54, agents
1346, live 121, gateway and shared 819, town 218, arbiter and engine 1728. The tip changed only
`chrome.css` and slice two was re-run green on it.

DOM tests: happy-dom is installed and goes per file via `// @vitest-environment happy-dom`.
Never put it in `vitest.config.ts`. Three traps, all measured: happy-dom replaces the global
`URL` so `new URL('./x.css', import.meta.url)` breaks `readFileSync` (use
`join(import.meta.dirname, f)`), vitest fake timers replace `requestAnimationFrame` so a
hand-rolled rAF stub passes vacuously, and React keeps a value tracker beside an input so
`el.value = x` does not fire `onChange`. `renderToStaticMarkup` needs no DOM and is right for
components. Only hooks need happy-dom.

Source-text assertions (`expect(SRC).toContain`) were 409 at the start of the drive and 286 in
web now. Write no new ones. `chromeCss.test.ts` is the one legitimate home, because no layout
engine runs in vitest.

### Build and run

```
pnpm --filter @sj/web build     # never `npx vite build`
pnpm stream                     # scripted, $0, http://localhost:8080 (on this box 8080 is taken: set PORT)
```

The gateway caches `index.html` at first read, so a build under a running server leaves it
serving an old index against deleted hashed assets. Build before launch and restart after
every dist swap.

### Rehearsals (spend real money)

```

`rehearse.sh` serves `packages/web/dist` as found. Build first. Set `SJ_LIVE=0` to prove the
wiring for nothing. A watcher must call a stall when `max(tick)` has not moved in fifteen
minutes. A frozen world keeps answering 200.

### Headless Chromium on this box

Attach CDP to the target with `type === 'page'`. Call `Emulation.setDeviceMetricsOverride`
AFTER `Page.navigate`. Pixi loads textures in a Web Worker, so use `Target.setAutoAttach` to
see their requests. `/home/ubuntu/fc/cdpurl.mjs` and `show-shots.mjs` are working examples.

   the bearer and 200 with it, then the same through `https://sanjunipero.deadpackets.pw`.
4. Watch the first hour: `docker compose logs -f town` for `alert:` lines. Expected spend about
   $0.78 per sim-day with twelve minds (r39), 670 to 800 calls per sim-day. Clock: 48 real
   minutes per watched sim-day, ten times slower unwatched (`SJ_IDLE_SPEED` 0.1), nights four
   times faster while everyone sleeps.
5. Rails: `SJ_SPEND_DAILY_USD` 30 per rolling real day, lifetime `SJ_SPEND_CAP_USD` 50 (raise

## 9. What the town taught us. Owner rulings and measured lessons

This section carries the controller's memory. Each entry is a ruling in the owner's words or
a fact measured on a numbered rehearsal (`rNN`). None of it is derivable from the code.

### The vision (2026-09-02, 2026-09-05, 2026-09-06)

> "a simulation that was pleasant to watch and follow. Agents would engage in easy-to-follow
> conversations that actually took turns. Agents would create customs, laws, rules, inventions.
> They would have memories and form relationships and unique personalities, and grow the town.
> They would fall in love or hate each other or even break up and remarry. I didn't want this to
> be scripted, I want it to emerge as organically as possible."

> "Go, autonomously. Just produce tables like you have been, showing how things are going. I
> trust you to make the best choices to make a fun watchable town, that is balanced and carefully
> paced to not be overwhelming. Cost efficiency and performance efficiency is important. ...
> let's aim for v2 fully deployed and feature complete."

> "This is meant to be Story focused, physics as a background or plot element. Deaths are
> supposed to be extremely rare or intentional. This needs to feel like a novel being played out
> in real time, but still an LLM simulation."

Open-ended invention (new verbs, laws, buildings, adjudicated by the arbiter) is the
differentiator over Smallville. Survival is a backdrop at most. The owner accepts architectural
change to get there. Every report to the owner is a table of measured numbers, story lens first,
cost and physics second.

### The pacing bar the owner approved (r44, 2026-09-08)

| What | Per real minute watched | One every |
|---|---|---|
| Lines spoken | 7.6 | 8 s |
| Acts started | 4.8 | 13 s |
| Scenes closed | 0.65 | 1.5 min |
| Something built (by a mind, past tick 1) | 0.01 | 1.5 h |
| A discovery | 0.06 in the first three days, then about one a sim-day | |
| A courtship turn | 0.02 | 50 min |

Measure these six before and after any pacing change and say so. Traps: `pacing.py` defaults to
a 3000 ms tick and r44 ran at 2000, so replaying without the clock reads every row at 0.667x.
Thirteen structures are seeded by WORLD at tick 1, so count only `structure_planned` with a
`builderId` past tick 1. r49 built 0.98 a sim-day once `learn_building` existed.

### Rarity rulings (2026-09-07)

Arrivals and births are rare (sim-weeks apart). Collapses and deaths are extremely rare and
never from a need alone (a murder, a disaster, a harsh disease). Courting is slow burn with
variance (some pairs fast, most slow, a per-person trait). One walk-out per day is the one
rail, and it limits how often, never with whom.

### Emergence, never levers (2026-09-08)

> "Affairs should be possible but organic. Listen, any type of social/romantic interaction ever
> (literally ever) should emerge organically and without prescripted or guided levers. All I ask
> is we detect the emergence of such things and show them to the user."

Two levers were removed: the engine refusing `court` and `lie_with` for a married body (only
`propose` still refuses, a body cannot hold two marriages), and the prompt line naming who you
walk out with (now just "You are married to Farida"). Replaced by detection: the chronicle names
the marriage when the pair walking out is not the marriage.

### Seeds are character, not plot (2026-09-06)

A founder card may carry fears, values, a grudge, a want about the person themselves. It may
never name a partner, a rival or an outcome. Move emergence with physics: roads on wants,
scarcity dials, time, affordances in perception.

### Cards cannot ask for physics (r45, r49)

Omar's value `sitting with the sick` in a valley where nobody can be ill made the town nurse
Salma's invented back for seven sim-days (18% of every scene). Before writing a value, ask what
event in the world pays it. If none, the minds will invent the event. Three seeds hid in prompts
(`founderMinds.ts` worries and example lines, `sceneLlm.ts` CLOSE_SYSTEM examples) and a test
now sweeps cards and prompts for ailment words on whole-word boundaries. The body block says
"Nothing hurts and you are not ill" so a well mind has something true to say.

### Prompt examples get copied (r39)

One named example in the nightly want prompt and five of twelve minds wanted that exact thing of
that exact person. Never give one example, never put a cast name in one, say "take the shape,
none of the words". And a rule the world enforces must be told to the mind in the same commit
(perception field plus prose line), or the refusal is invisible.

### Shared fiction drift (r40, corrected r44)

A mind asked about a person it cannot see would rather answer than admit it has not looked, the
next turn reads it back as fact, the scene close records it, three turns is enough. Fixed in
`RULES_OF_BEING`: say you do not know, or say who told you. The lens must count care being
ARRANGED around a body the world has not marked, not worried sentences, or it stops a healthy
run. At every soak checkpoint, take one claim the minds make about a body and check it against
the snapshot.

### Plain speech (2026-09-06)

> "any human facing text does not contain mannered prose, sounds human and casual ... 'Halim
> greets Dilara inside; nothing changes between them' is not how normal humans read text."

`PLAIN_SPEECH` rides every viewer-facing prompt. Read a line out loud across a kitchen table. No
semicolons, no "nothing changes", contractions where a person would use them. Luna writes curly
apostrophes, so a contraction count must match U+2019. Judge every rehearsal's beats and titles
against this first.

### Needs are social, not survival (2026-09-05, 2026-09-07)

> "we don't want hunger and thirst to bite too hard, because the simulation will just turn into
> survivability." Then: "agents should eat once a sim-day. But we need to make it work without
> them collapsing."

Landed: the appetite clock is decoupled from the hunger bar. `lastMealTick` on the body,
`hoursSinceMeal` in perception, a meal due line at 20 h with the food road, the eat verb refuses
a full body that already ate today. Bar decay 0.005 per tick (13 days to empty), 20 days from
last meal to grave. Every collapse checked in r24 to r26 was ENERGY, not hunger: awake decay
0.065 gives a 24 h budget. Per-person appetite (0.7 to 1.5) was built on `v2-eating-traits` as
a quick test and was folded on the owner's ruling. Food demand is about 12 units a sim-day.

### Founder sex was never told (fixed `e8caeb05`)

Every founder body read as female because `agent_spawned` never carried `sex` and `sexOf()`
defaulted to `'f'`. So conception was impossible in every run (0 proposals, 0 births across
r37 to r49) and every inventor was told as "she". `FOUNDER_SEX` now lives in
`cityTemplate.ts` and a test pins it to the cards. The tell for this class of bug is a count
that is exactly zero across every run while the wiring reads complete: read the folded event
payload, not the prompt.

### Founding is by household

`SJ_FOUNDERS` rounds down to a whole household: sizes 3, 4, 6, 7, 12. Groups: [omar, nadia,
salma], [yusuf], [farida, bashir], [amara], [halim, dilara, tariq, kamal, leyla]. Production
runs six. Arrivals come every 21 to 35 sim-days and after the four authored travellers
`whoIsComing` mints new people up to `SJ_MAX_MINDS`. Never add a card that names somebody
without both in one group.

### Growth doors were shut (fixed `65c6510b`, `83cfd783`, `16ae6e9a`)

A building could not be invented (`DiscoveryKind` had no structure case): now `learn_building`
lands as one `config_changed` at `structures.recipes.<kind>`, the road `state.laws` already
travels, so it folds, hashes and replays. Probed: "somewhere to sit of an evening and drink"
returned an alehouse. A council could not be convened because no mind could make the first
proposal: the register is now taught as its own paragraph beside "anything you can name, you can
try", not buried in the `speak:` grammar. Money and jobs are still not reachable.

### A dud grant squats on the name (r49)

The court granted `recipe:grind_wheat` that made nothing and `nearDuplicate` then refused every
honest attempt as a second name for it. Two holes closed: `gain_skill` left `CHANGES_WORLD`, and
the sanity gate reads each row that claims to work. Check `makes=[]` on every craft.

### The society layer blocker (2026-09-03)

`adjudicate.ts` records the CORRECTED verdict, so read `class='beyond_adjacency'` and never the
kind when counting attempts. Every attempt in r6 to r8 died on canon adjacency, which alone did
not retry. Fixed to retry like its siblings.

### The fleet and the money

- Minds: `openai/gpt-5.6-luna` served by OpenAI, pinned in `packages/llm/src/pins.ts`.
  Rulings at `xhigh`, turns and spoken lines at `high`, summarisers at `minimal`. Cache read is
  ten times cheaper than input, so cache hit is THE cost lever, then the idle gap, then effort.
  Reasoning at high is 14% of a turn. Turn cadence is `max(idleGapTicks, latency)` = 15
  sim-minutes at any speed, and activity begets turns (a neighbour's act is what wakes you).
- Measured cost: $0.70 to $0.87 per sim-day for twelve minds, flat across a run. Prompt growth
  is linear and small (autobiography capped to the last 7 paragraphs). 23k events a sim-day,
  about 8 MB. Disk is fine for months.
- Cache TTL through OpenRouter is between 19 and 41 minutes after last use.
  `prompt_cache_retention: '24h'` is not honoured on this route.
- Both provider bake-offs came back REJECT (2026-09-10): images stay on
  `google/gemini-3.1-flash-image` (the only model whose master pixel pitch clears
  `MASTER_MIN_PITCH 6`, real price $0.1028 a call not the listed $0.00006, a character is 8
  image calls), minds stay on luna (deepseek-v4.1-flash cost 19% more per USABLE turn because
  36.7% of its calls produced nothing). Two traps: `SJ_MIND_MODEL` alone kills 100% of calls
  because `PROVIDER_ORDER` is pinned to OpenAI, and the tool transport has no repair rung
  (`client.ts` around line 412 discards `r.text` on the no-tool-call branch, the prose where the
  valid turn sits).
- Reading `_ops.db`: group by (provider, model), never provider alone. A doze is usually our own
  admission gate (`AdaptiveLimiter`, `no slot` alerts), not the provider.
- Idle hours: `boredomTicks` 60 in `wake.ts` is the cadence (a mind acts 1 to 3 minutes then
  stands an hour). The lever is 30 or 45 at about +$0.15 to 0.20 a sim-day.

### The forge ceiling

A character is 9 authored cells (2 facings x 4 poses + 1 sleep), the rest mirrored. Every
shipped atlas baked the sleep mirror backwards and `passing-b` duplicates `passing-a`. The fix
is a $0 regeneration through the corrected `mirror.ts`, never a hand edit of a generated
manifest (three reviewers caught that). Measure on opaque pixels only, RGB.

### Process rulings

- Opus subagents build, the Fable main thread reviews every diff itself as the senior engineer
  and runs every gate. A reviewer subagent may run in addition, never instead.
- Lanes by strict file ownership. Three or four adversarial review lenses (law, viewer, tests,
  seams) after every phase. Every phase shipped at least one lane that built a pure module
  nothing called: **always ask a reviewer to trace from the event to the pixel and name the
  line.** Brief every lane to measure first and prove red-on-old.
- Ultracode workflows for audits. Never let a lane stage files.
- A listing is not a capability test: probe the model. Never swap a roster the owner named.

## 10. The audit and what it got wrong

The ponytail audit (`/ponytail:audit`: over-engineering only, never correctness, the whole tree)
ran as an ultracode workflow, one lane per package plus root, then dedup, then adversarial
verification of every `delete`. The owner: "Everything is approved as long as it does not
affect the quality of the town simulation."

Applied in total: 62 of 124 findings, about 1,275 shipped lines out and one dependency
(`playwright-core` escape in knip) removed. Not the 2,062 the audit claimed, because:

- The audit's error rate was about one claim in twenty, always on "these are duplicates":
  three median downsamplers are three contracts, `borderReport` sums a ring not a window,
  `frontier()` and `frontierNames()` select different columns, the `TopTwo` tracker's tie order
  feeds a viewer string, `assetsHttp`'s foot bar is what a test uses to tell two contacts apart.
- Two ★-pinned tests the audit missed (`interiorMap.test.ts:259`, `roomShell.test.ts:831`).
- The `AdminPane` extraction came out larger both ways.
- The minds lane applied 2 of 28 on purpose. Twenty-six findings there have merit and were
  skipped on the boundary. A future session may take them one at a time with a rehearsal
  behind each.

Two new ★ proofs came out of it: `forge/src/collapse.test.ts` (27 tests, the shared flood fill
and mean-RGB helpers are byte-identical to the seven loops they replaced, run against real

## 12. Toolchain facts that cost an afternoon each

- Biome, never Prettier. `npx biome check` reports hundreds of pre-existing import-order assists
  and is not the gate.
- `pnpm --filter @sj/web build`, never `npx vite build`.
- A grid track of `auto` beside `minmax(0, 1fr)` starves the fr track (measured at 390 px: the
  flank took 295 of 390). Both flanks take a share and wrap.
- `#E8785A` and its family are `MASTER_PALETTE` entries, not stray hexes. A test reads the forge
  chart off disk and measures every colour any web source writes against it, including the 19
  world-art constants that name a token in a comment.
- `--f-8` does not exist and cannot: the ladder is closed at seven and a test holds it.
- `awake` is a banned literal in viewer text. Count from the sleeping side.
- No non-accent token clears 3:1 on both grounds. `--sky` cannot be an edge colour (2.27:1 on
  night). No single ground carries all four book colours as a hairline.
- The gateway sends the director frame BEFORE the board frame, and board rows carry no beatId
  (the holder matches on `sceneId|cast`). The pre-roll is `STICKY = 1.25`, not a timer.
- The camera's cut agrees with the ribbon's head on only about 45% of ticks, on purpose (the
  screen-fatigue divisor). About 30% of ticks the town is quiet, so every surface must read
  well when nothing is hot.
- `packages/gateway/scripts` is the only thing outside `packages/web` that imports web source.
- Rehearsal watchers that only check the port are blind. Read `max(tick)`.
- The harness kills a long foreground command for memory before vitest finishes a large set.
  One slice, one call.
- Chromium cannot read `/tmp`. Put harness files under the home directory.
