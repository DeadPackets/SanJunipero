## 3. The laws

These are standing. Every one of them was paid for.

### Money and secrets

- **Never read, print, cat, echo or log `.env` or `OPENROUTER_API_KEY`.** A live script runs as
  `node --env-file=<repo>/.env --import tsx <script>` and its output goes through `grep -v sk-`.
- Every call is booked to `_ops.db` at the rate the account is charged. The ledger resumes with
  the town, so a restart never resets a budget.
- Guards on a live town: daily budget `SJ_SPEND_DAILY_USD`, lifetime cap `SJ_SPEND_CAP_USD`,
  rate tripwire (22 calls per mind per sim-hour over 15 min), projection alert ($2.50 per
  sim-day), provider mix. The first three stop the minds and leave the town serving. The last
  two only speak.
- Spend is unlocked by the owner (no per-task caps) which makes unrequested spend worse, not
  better. Never substitute a roster the owner named. Probe a model before trusting a catalogue.

### Production

- The box is production. **Never start, stop, rebuild or `compose down` the production town
  without the owner saying go**, in a user turn, for that action.
- nginx exposes only 8090. `docker compose --profile edge` must never run here (80 and 443 are
  taken by four other sites).
- Rehearsals and shows run on 8099 with admin on 8799.

### Git

- Never `git pull`. Never bare `git stash` (if you must: `git stash push -u -m <tag>`, apply by
  SHA, drop by tag). Prefer a WIP commit.
- Kill processes by PID, never `pkill -f` or `pgrep -f`. Other people's processes match those
  patterns on this box.
- Lanes (subagents) must never stage files. A `git commit` from any path commits the whole
  shared index. Two commits of this drive swept another lane's staged deletions and do not
  typecheck on their own (`be5e8a02`, `5793fdd4`). The tip does.
- Commit attribution the owner asked for is at the foot of every commit of this drive:
  `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` and a `Claude-Session:` line.

### Tests and gates

- **Never run the whole suite. Never run knip.** The full run trips a vitest reporter timeout
  under load and reports a phantom failure, and knip counts a test as a use in this repo
  (`knip.json` lists `**/*.test.ts` as an entry), so it can never find a symbol reached only by
  its own test. Grep for callers by hand.
- One vitest at a time, one gate step per foreground call. A sequential script running the
  whole gate was killed for memory.
- A full gate must name `packages/live` and `packages/town`. Both catch seams that unit tests
  cannot, and both have shipped red tips. `g6.test.ts` (two viewers fold the same events to the
  same bytes over three sim-days) and `liveSeam.test.ts` (the scripted path never loads the mind
  stack) are the proof for any engine or town change.
- Never run any test suite while a rehearsal is running.
- A `★` in a test name or comment is a load-bearing line. Read it before you change what it
  pins. It wins against an audit finding every time.

### Writing

- Plain modern English everywhere a person reads, including a mind's prompt and the town's own
  paper. No captions, no semicolons, no em dashes, no lists of three for rhythm.
- Comments default to none, cap two lines, and only for a constraint the code cannot show.
- Formatting is Biome (`npx biome format --write <files>`), never Prettier.

### Design laws

1. **Physics, never outcomes.** The engine says what wood, rain, hunger and walls do. It never
   says what anybody should do about them. A want is made in the world, not in a prompt.
2. **Story first, never state.** The screen answers who wants something, what is in the way and
   how long it has been going on. It may never state something the world does not hold.
3. **Emergence, never levers.** Nothing steers who likes whom. The world holds facts and refuses
   only what a body cannot do. If a run misbehaves socially, build the lens, not the rule.
4. **The one-way glass.** No operator word reaches a mind (`glassScan`). No story rule reaches a
   mind either.
5. **Additive protocol only.** `PROTOCOL_VERSION` is 8. An unknown frame is dropped in a
   try/catch on the client, so new frames are safe and changed frames are not.
6. The viewer's own rules: no bare unbounded integer on screen, de-emphasis is a colour never an
   opacity, font sizes only `--f-1` to `--f-7` (12/13/14/16/18/22/28), motion only `--t-slow`
   (300 ms) `--t-med` `--t-move` `--stagger`, `contrast.test.ts` holds closed rosters of roles
   and quiet sites, `chromeCss.test.ts` derives the marks the frame places and bans `position`
   on any of them.

### Tests, the way that works on this box

One vitest at a time, each in its own foreground call, all at
`--poolOptions.forks.maxForks=1 --silent=true`:

Last measured counts at `42262fd6` (before the CSS-only tip): web 1411 + 1575 + 54, agents
1346, live 121, gateway and shared 819, town 218, arbiter and engine 1728. The tip changed only
`chrome.css` and slice two was re-run green on it.

DOM tests: happy-dom is installed and goes per file via `// @vitest-environment happy-dom`.
Never put it in `vitest.config.ts`. Three traps, all measured: happy-dom replaces the global
`URL` so `new URL('./x.css', import.meta.url)` breaks `readFileSync` (use
`join(import.meta.dirname, f)`), vitest fake timers replace `requestAnimationFrame` so a
hand-rolled rAF stub passes vacuously, and React keeps a value tracker beside an input so
`el.value = x` does not fire `onChange`. `renderToStaticMarkup` needs no DOM and is right for
components. Only hooks need happy-dom.

Source-text assertions (`expect(SRC).toContain`) were 409 at the start of the drive and 286 in
web now. Write no new ones. `chromeCss.test.ts` is the one legitimate home, because no layout
engine runs in vitest.

### Build and run

```

pnpm stream                     # scripted, $0, http://localhost:8080 (on this box 8080 is taken: set PORT)
```

The gateway caches `index.html` at first read, so a build under a running server leaves it
serving an old index against deleted hashed assets. Build before launch and restart after
every dist swap.

## 9. What the town taught us. Owner rulings and measured lessons

### The vision (2026-09-02, 2026-09-05, 2026-09-06)

> "a simulation that was pleasant to watch and follow. Agents would engage in easy-to-follow
> conversations that actually took turns. Agents would create customs, laws, rules, inventions.
> They would have memories and form relationships and unique personalities, and grow the town.
> They would fall in love or hate each other or even break up and remarry. I didn't want this to
> be scripted, I want it to emerge as organically as possible."

> "Go, autonomously. Just produce tables like you have been, showing how things are going. I
> trust you to make the best choices to make a fun watchable town, that is balanced and carefully
> paced to not be overwhelming. Cost efficiency and performance efficiency is important. ...
> let's aim for v2 fully deployed and feature complete."

> "This is meant to be Story focused, physics as a background or plot element. Deaths are
> supposed to be extremely rare or intentional. This needs to feel like a novel being played out
> in real time, but still an LLM simulation."

Open-ended invention (new verbs, laws, buildings, adjudicated by the arbiter) is the
differentiator over Smallville. Survival is a backdrop at most. The owner accepts architectural
change to get there. Every report to the owner is a table of measured numbers, story lens first,
cost and physics second.

### The pacing bar the owner approved (r44, 2026-09-08)

| What | Per real minute watched | One every |
|---|---|---|
| Lines spoken | 7.6 | 8 s |
| Acts started | 4.8 | 13 s |
| Scenes closed | 0.65 | 1.5 min |
| Something built (by a mind, past tick 1) | 0.01 | 1.5 h |
| A discovery | 0.06 in the first three days, then about one a sim-day | |
| A courtship turn | 0.02 | 50 min |

### Rarity rulings (2026-09-07)

Arrivals and births are rare (sim-weeks apart). Collapses and deaths are extremely rare and
never from a need alone (a murder, a disaster, a harsh disease). Courting is slow burn with
variance (some pairs fast, most slow, a per-person trait). One walk-out per day is the one
rail, and it limits how often, never with whom.

### Emergence, never levers (2026-09-08)

> "Affairs should be possible but organic. Listen, any type of social/romantic interaction ever
> (literally ever) should emerge organically and without prescripted or guided levers. All I ask
> is we detect the emergence of such things and show them to the user."

Two levers were removed: the engine refusing `court` and `lie_with` for a married body (only
`propose` still refuses, a body cannot hold two marriages), and the prompt line naming who you
walk out with (now just "You are married to Farida"). Replaced by detection: the chronicle names
the marriage when the pair walking out is not the marriage.

### Seeds are character, not plot (2026-09-06)

A founder card may carry fears, values, a grudge, a want about the person themselves. It may
never name a partner, a rival or an outcome. Move emergence with physics: roads on wants,
scarcity dials, time, affordances in perception.

### Cards cannot ask for physics (r45, r49)

Omar's value `sitting with the sick` in a valley where nobody can be ill made the town nurse
Salma's invented back for seven sim-days (18% of every scene). Before writing a value, ask what
event in the world pays it. If none, the minds will invent the event. Three seeds hid in prompts
(`founderMinds.ts` worries and example lines, `sceneLlm.ts` CLOSE_SYSTEM examples) and a test
now sweeps cards and prompts for ailment words on whole-word boundaries. The body block says
"Nothing hurts and you are not ill" so a well mind has something true to say.

### Prompt examples get copied (r39)

One named example in the nightly want prompt and five of twelve minds wanted that exact thing of
that exact person. Never give one example, never put a cast name in one, say "take the shape,
none of the words". And a rule the world enforces must be told to the mind in the same commit
(perception field plus prose line), or the refusal is invisible.

### Shared fiction drift (r40, corrected r44)

A mind asked about a person it cannot see would rather answer than admit it has not looked, the
next turn reads it back as fact, the scene close records it, three turns is enough. Fixed in
`RULES_OF_BEING`: say you do not know, or say who told you. The lens must count care being
ARRANGED around a body the world has not marked, not worried sentences, or it stops a healthy
run. At every soak checkpoint, take one claim the minds make about a body and check it against
the snapshot.

### Plain speech (2026-09-06)

> "any human facing text does not contain mannered prose, sounds human and casual ... 'Halim
> greets Dilara inside; nothing changes between them' is not how normal humans read text."

`PLAIN_SPEECH` rides every viewer-facing prompt. Read a line out loud across a kitchen table. No

apostrophes, so a contraction count must match U+2019. Judge every rehearsal's beats and titles

### Needs are social, not survival (2026-09-05, 2026-09-07)

> "we don't want hunger and thirst to bite too hard, because the simulation will just turn into
